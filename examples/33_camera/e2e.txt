# E2E: camera pan + follow (deterministic CRC baked in)
# Preconditions: 640×360 / fixed background / fixed world / FixedTimeStep 60Hz / harness virtual clock
# CRC oracle is the aarch64-darwin capture. Re-capture on other platforms if it diverges.
# Example run:
#   TMPD=$(mktemp -d)
#   VP_HEADLESS=1 VP_HARNESS_SCRIPT=examples/33_camera/e2e.txt \
#     VP_HARNESS_OUT=$TMPD zig build run-example_33
# snapshot with path omitted → $VP_HARNESS_OUT/frame_<n>.png (do not leave PNGs in the repo)

# --- 1. Initial view (checkerboard + marker sprite) ---
step 1
snapshot fb
digest fb
expect fb crc=11D17951

# --- 2. Manual scroll (RIGHT held) ---
inject key_down RIGHT
step 40
inject key_up RIGHT
snapshot fb
digest fb
expect fb crc=47CA82D8

# --- 3. Move near the boundary (RIGHT+DOWN) ---
inject key_down RIGHT
inject key_down DOWN
step 100
inject key_up RIGHT
inject key_up DOWN
snapshot fb
digest fb
expect fb crc=B81EB721

# --- 4. After follow enables (lerp in progress; sprite enters view) ---
inject key_down F
step 1
inject key_up F
step 40
snapshot fb
digest fb
expect fb crc=EE378351

# --- 5. Stable after follow (target near viewport center) ---
step 80
snapshot fb
digest fb
expect fb crc=A775CEB8
quit
