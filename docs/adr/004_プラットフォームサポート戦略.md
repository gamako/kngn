# ADR-004: プラットフォームサポート戦略 - Linux/X11の除外

**Status:** 承認
**Date:** 2025-10-25
**Category:** プラットフォーム戦略

## 概要

video-protoプロジェクトがサポートするプラットフォームの優先順位と、特にLinux環境でX11を除外する決定について記録する。

**決定内容：**
- 初期実装はmacOSのみサポート
- 将来的にWindowsとLinux/Waylandを優先
- Linux/X11は当面サポートしない（需要があれば再検討）

## 背景

イベント処理システムの設計において、キーリピート検出機能の実装可能性を各プラットフォームで調査した結果、プラットフォーム間で大きな差があることが判明した。

### 各プラットフォームのキーリピート検出能力

| プラットフォーム | リピート検出API | 実装難易度 | 精度 |
|----------------|--------------|-----------|------|
| macOS | `[event isARepeat]` | 簡単 | 完璧 |
| Windows | `lParam & 0x40000000` | 簡単 | 完璧 |
| Linux/X11 | なし（回避策あり） | 困難 | 中程度 |
| Linux/Wayland | 専用コールバック | 中程度 | 完璧 |

## 検討した選択肢

### Option 1: 全プラットフォームサポート（却下）

**内容：** X11を含む全ての主要プラットフォームをサポート

**メリット：**
- 最大限の互換性
- 既存のX11ユーザーを取り込める
- SSH X転送が使える

**デメリット：**
- X11でのキーリピート検出が不確実（タイムスタンプ比較などの回避策が必要）
- コードベースが複雑化
- テストマトリックスの増大
- メンテナンスコストの増加

### Option 2: X11を除外（採用）

**内容：** Linux環境ではWaylandのみをサポート、X11は除外

**メリット：**
- コードベースがシンプルになる
- キーリピート検出を「保証される機能」として扱える
- テストマトリックスが削減される
- メンテナンスコストの削減

**デメリット：**
- 既存のX11ユーザーを切り捨てる
- SSH X転送が使えない
- 一部のLinuxディストリビューションで動作しない
- WSL1環境で動作しない（X11依存）

## 決定理由

**X11を除外することを決定した理由：**

1. **技術的複雑性**
   - X11には直接的なキーリピート判定APIが存在しない
   - XkbSetDetectableAutoRepeatなどの回避策はあるが、完全ではない
   - 実装の複雑性がプロジェクトの「シンプルさ優先」原則に反する

2. **将来性**
   - Waylandが2008年から開発され、主流になりつつある
   - Ubuntu 22.04 LTSはデフォルトでWayland
   - 多くのディストリビューションがWaylandへ移行中

3. **リソースの制約**
   - 限られた開発リソースで品質を保つため
   - 現時点でLinuxサポート自体が未実装
   - 需要が明確になってから対応しても遅くない

4. **API設計への好影響**
   - キーリピート検出を全プラットフォームで保証できる
   - APIドキュメントがシンプルになる
   - 一貫性のある動作を提供できる

## 段階的サポート計画

### Phase 1: Core Platform（現在）
```yaml
必須サポート:
  - macOS (Metal/Swift/ObjC)
```

### Phase 2: Desktop Expansion（将来）
```yaml
必須サポート:
  - macOS
  - Windows (Win32/DirectX)

実験的サポート:
  - Linux/Wayland
```

### Phase 3: 需要に応じて（もっと将来）
```yaml
追加検討:
  - Linux/X11  # 需要があれば
  - Web (WebAssembly)  # 新しい可能性
```

## 影響

1. **API設計**
   - `is_repeat`フラグを全プラットフォームで保証できる
   - プラットフォーム固有の条件分岐が減る

2. **ドキュメント**
   - "Key repeat detection is guaranteed on all supported platforms"
   - "Linux support requires Wayland (X11 support may be added in future)"

3. **実装**
   - platform_linux_x11.c の実装は不要
   - platform_linux_wayland.c のみを将来実装

## 他プロジェクトの事例

| プロジェクト | X11対応 | Wayland対応 | 戦略 |
|-------------|---------|------------|------|
| GLFW 3.4 | ✅ | ✅ | 完全な互換性重視 |
| SDL3 | ✅ | ✅優先 | Wayland-first設計 |
| winit (Rust) | ✅ | ✅ | 両方サポート |
| Raylib | ✅ | ❌ | X11のみ（シンプル重視） |

video-protoは「シンプルさ優先」の原則に従い、Wayland-first戦略を採用する。

## 再検討の条件

以下の条件が満たされた場合、X11サポートを再検討する：
- 明確なユーザー需要がある
- X11でのキーリピート検出の確実な方法が見つかる
- 開発リソースに余裕ができる
